# Glossary — one-liners

Look things up here mid-lesson; full explanations live in [Lesson 2](02-key-concepts.md).

- **LLM** — the AI brain; predicts text, well enough to reason and code
- **Model** — a specific LLM (bigger = smarter/slower/pricier, smaller = faster/cheaper)
- **Token** — word-fragment; the unit of AI cost and memory
- **Context window** — the model's working memory for this conversation
- **Dumb zone** — the overfull end of the context window where quality quietly degrades
- **Prompt** — your instruction to the model
- **System prompt** — the standing job description the model gets before your message
- **Repo** — a project folder with full change history
- **Git** — the tool that keeps that history
- **GitHub** — the website where repos live online
- **Clone** — copy a repo from GitHub to your machine
- **Commit** — a saved checkpoint in the repo's history
- **Push** — send your commits up to GitHub
- **Markdown** — plain text with simple formatting; the paper of AI work
- **CLAUDE.md** — standing instructions Claude Code reads at the start of every session
- **Script** — a small program that does one tedious job
- **Agent** — AI that acts in a try-check-adjust loop, not just answers
- **Skill** — packaged, reusable know-how you teach the system
- **API** — how programs order services from other programs; usually metered and billed
- **MCP** — the universal adapter that connects tools (calendar, email, databases) to Claude
- **Hallucination** — confident, plausible, wrong; the reason we verify everything
- **Terminal** — the text window where you type commands; the honest interface
- **VS Code** — the editor where you see your files and run Claude Code
- **Node.js** — the runtime many tools are built on; installed once, then invisible
- **Deploy** — publish to the live internet
- **Vercel** — the service that auto-publishes your repo every time you push
- **Localhost** — your site running privately on your own machine before deploying
- **Plan mode** — Claude Code mode that discusses and plans without touching files
