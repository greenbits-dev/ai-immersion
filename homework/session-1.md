# Homework after Session 1

*Time: ~45 minutes total. Everything here is safe — no way to break anything.*

## 1. Accounts and downloads (~20 min)

From the [setup checklist](../03-setup.md), do **steps 1–4 only**:

1. Install VS Code
2. Create your GitHub account (username will be public — choose accordingly)
3. Install git
4. Install Node.js

Each step says what success looks like. **Stop at step 4** — we install Claude Code together in session 2, so any errors happen in the room.

Hit an error? Copy the WHOLE message, paste it to Claude (claude.ai is fine) with "I was installing X on a Mac/Windows and got this." That ferrying move is itself part of the course.

## 2. Watch (~25 min of your pick)

- First choice: start Karpathy's **"Intro to Large Language Models"** on YouTube (watch as much as holds your attention; finish it over the week).

## 3. Think (5 min, no computer)

Write down, anywhere: **what would you build if building were easy?** One line is enough. Bring it to session 2 — the first projects come from this list.

## Optional, for the curious

Re-read [Lesson 2](../02-key-concepts.md) and try the self-check questions at the bottom.
