# Homework after Session 3

*You've seen the plan → prompt → build → verify → deploy loop. Run one tiny loop alone.*

## 1. One solo micro-loop (~30 min)

In the course repo (or any folder), start `claude` and run one complete loop on something harmless. Ideas:

- "Plan first, don't build: I want a markdown file that's a packing checklist template for my trips. Ask me questions, then propose a plan."
- Approve → let it build → **verify** (open the file, is it actually right for you?) → request one change.

The content doesn't matter. The shape does: you planned, you defined done, you verified, you iterated.

## 2. Start your log

Ask Claude: *"Create a log.md in this folder. Add today's entry: what we did and what's next."* Principle 2 starts now — every session from here on ends with a log line.

- Re-read [Lesson 6 — First project](../06-first-project.md), especially Step 0.
- **Do Step 0** (decide your site's content, on paper). Session 4 moves fast; people with content ready ship in the room.
